# 蜜雪冰城打工模拟器

一个 Three.js 做的 3D 网页小游戏：扮演奶茶店打工人，捶柠檬、打甜筒、摇奶昔，伺候好每一位奇葩顾客。

> 非官方同人作品，与品牌方无关。游戏里的角色、吉祥物、图案和音乐均为原创。

## 运行

需要 Node.js 18 以上。

```bash
npm install
npm run dev
```

Windows 下也可以直接双击 `start.bat`。

## 玩法

- 看顾客头顶的小票：要什么、几分糖、加不加冰。
- 拿杯子 → 按配方点原料 → 封口 → 点小票出餐。
- 捶水果：点柠檬或鲜橙放上案板，再连点案板（或按空格）。
- 打冰淇淋：按住冰淇淋机，在绿色区间松手，打过头会塌。
- 摇奶昔：先封口再摇，不然洒一身。
- 营业额是老板的，你拿底薪、小费和达标奖金，钱可以在员工小卖部买升级。店铺评分跌到底会被开除。

快捷键：`1` `2` `3` 给对应窗口出餐，`空格` 捶水果，`X` 倒掉，`Tab` 配方表。

## 内容

- 10 款饮品、13 种顾客，按天数逐步解锁。
- 奇葩顾客：急急国王、小学生、谜语人、甜度狂魔、改单王、健身教练、热恋情侣、探店主播、砍价阿姨、社恐青年、外卖骑手、微服私访的区域经理。
- 所有模型、贴图和音效都由代码生成，没有外部素材文件。

## 结构

| 文件 | 内容 |
| --- | --- |
| `src/data.js` | 原料、配方、顾客类型、升级、评分规则 |
| `src/game.js` | 营业流程、调配、出餐、经济 |
| `src/world.js` | 渲染、灯光、店铺和街景模型 |
| `src/stations.js` | 操作台设备模型 |
| `src/character.js` | 顾客角色模型和动画 |
| `src/drink.js` | 饮品杯、甜筒、冰淇淋模型 |
| `src/ui.js` | 界面 |
| `src/audio.js` | 合成音效和背景音乐 |
